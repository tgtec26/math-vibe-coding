## 이 파일들을 만든 프롬프트 (복붙해서 자기 반 버전 만들기)

AI 코딩 도구(Claude, ChatGPT, Gemini 등 아무거나)에 아래를 그대로 붙이면 비슷한 것이 나옵니다. 굵은 부분만 바꾸면 다른 단원용이 됩니다.

### 1. 함수 탐험기

```
[9수02-15] 일차함수 y=ax+b, [9수02-22] 이차함수 y=a(x-p)²+q 탐구 도구.
- 탭으로 일차/이차 전환
- 각 계수는 슬라이더 (a: -5~5 step 0.5, b: -8~8 step 1 / 이차는 a≠0, p,q: -6~6)
- 왼쪽: 좌표평면 -10~10 격자에 그래프. 일차함수는 y절편 점과 "기울기 삼각형"(x로 1, y로 a) 표시. 이차함수는 꼭짓점과 축 점선 표시
- 오른쪽: 큰 글씨 수식 (y = 2x − 3 처럼 자연스럽게), 성질 (기울기, x절편, y절편 / 꼭짓점, 축, 최댓값·최솟값, 볼록 방향), x=-3..3 함숫값 표
- "도전 모드": 랜덤 점선 그래프를 보여주고 슬라이더로 똑같이 만들면 정답. 틀리면 "기울기를 더 크게" 식으로 힌트
- "5문제 레이스": 이름 입력 후 시작하면 게임처럼 전체 화면으로 전환(스크롤 없음). 3·2·1 카운트다운 뒤 숨은 그래프 5개가 차례로 나오고, 슬라이더가 정답과 일치하는 순간 "정답!" 플래시 + 짧은 효과음(Web Audio로 합성, 음원 파일 없음) + 폭죽 파티클 + 독려 멘트("절반 넘었어요!", "마지막 하나!" 등 진행 단계별)와 함께 자동으로 다음 문제. 완주 시 팡파르와 대형 폭죽. 상단에 효과음 끄기 버튼(교실용, 설정 기억). 상단에 진행 점 5개, 문제 번호, 큼직한 타이머(0.1초 단위), 나가기 버튼(Esc). 화면에는 그래프와 큰 슬라이더만. 완주하면 총 시간, 문제별 식과 소요 시간 표, "결과 이미지 만들기" 버튼 → 이름·날짜·총 시간·5문제 표·마지막 그래프가 담긴 PNG 저장(자동 저장이 막힌 환경이면 화면의 이미지를 길게 눌러 저장). "다시 도전"으로 즉시 재시작
```

> 레이스 결과 이미지는 학생 제출용. 교사는 이름·시간·5문제 식을 한 장으로 받음.

### 2. 확률 실험실

```
[9수04-06] 확률 = 상대도수 ↔ 경우의 수의 비율 연결 도구.
- 실험 선택: 주사위 1개(눈), 주사위 2개(눈의 합), 동전 3개(앞면 개수)
- 버튼: 1번 / +10 / +100 / +1,000 / +10,000 / +100,000 / 처음부터
- 1번 던지면 주사위 눈을 큰 유니코드 기호(⚀⚁⚂⚃⚄⚅)로 표시
- 왼쪽: 결과별 상대도수 막대 + 수학적 확률을 점선으로 겹쳐 표시, 아래에 도수·상대도수·수학적 확률(분수와 소수) 표
- 오른쪽: 관찰할 사건을 고르면 "시행 횟수(로그 눈금) vs 상대도수" 꺾은선이 수학적 확률 점선으로 수렴하는 그래프
- 상단에 총 시행 횟수, 상대도수, 수학적 확률, 차이를 크게
```

### 3. 표본과 신뢰구간

```
[12확통03-05~07] 표본평균의 분포와 모평균의 신뢰구간 시뮬레이터.
- 모집단: 프리셋(고3 남학생 키 μ=173 σ=6 등) 또는 μ, σ 직접 입력. 정규분포 가정
- n 슬라이더 2~100, 신뢰도 90/95/99% 선택
- 버튼: 표본 1개 추출 / 표본 100개 추출 / 처음부터
- 그래프 1: 모집단 곡선 위에 이번 표본의 값들을 점으로, 표본평균을 굵은 선으로, 신뢰구간을 가로 막대로
- 그래프 2: 지금까지 뽑은 표본평균들의 히스토그램 + 이론 곡선 N(μ, σ/√n) 점선 + 모집단 곡선(비교용). 표본평균들의 평균·표준편차를 μ, σ/√n과 나란히 표시
- 그래프 3: 최근 100개 신뢰구간을 가로선으로 쌓아서 그리고, μ를 포함하면 초록·놓치면 빨강. "100개 중 95개 (95%)"처럼 큼직하게
```

### 4. 추세선과 경사하강법

```
[12인수04-02~04] y=ax 추세선, 손실함수, 경사하강법 시각화. (교육과정: y=ax 형태, 일변수 손실함수만)
- 왼쪽: 0~10 좌표평면. 프리셋 데이터(공부시간→점수 등) 또는 빈 화면에서 클릭으로 점 추가. 추세선 y=ax와 각 점의 오차를 세로 선분으로. 기울기 a 슬라이더(0~3)
- 오른쪽: 손실함수 L(a) = (1/n)Σ(yᵢ − a·xᵢ)² 곡선. 현재 a 위치에 점과 접선, L(a)와 접선의 기울기 L′(a) 숫자 표시, 최적 a 점선
- 학습률 η 슬라이더, "한 걸음 내려가기" 버튼(a ← a − η·L′(a)), "자동 실행", "a를 다시 놓기"
- 표: 단계, a, L(a), L′(a), 다음 a — 최근 8단계
- 학습률이 크면 발산하는 것도 그대로 보이게
```

## 수업에서 쓰는 흐름 (예)

**함수 탐험기 (1차시 후반 15분)**
1. 교사 프로젝터: b만 움직이며 "무엇이 변하고 무엇이 그대로인가" 발문
2. 학생 태블릿: 도전 모드 3문제, 옆 사람과 힌트 문장을 수학 용어로 바꿔 말하기
3. 정리: 표의 y값 차이가 왜 항상 a인지 설명 쓰기

**확률 실험실 (도입 10분)**
1. 10번만 던지고 상대도수 표 보며 "확률이 이거인가?" 논쟁
2. 10만 번 → 수렴 그래프. "몇 번쯤부터 믿을 만한가" 토론
3. 동전 3개: 앞면 1개·2개 확률이 같은 이유를 경우의 수로

**표본과 신뢰구간 (2차시 탐구)**
1. n=4로 100개 뽑고 구간 폭 기록 → n=100으로 반복. √n 관계 추측
2. 신뢰도 99%로 바꾸면 얻는 것·잃는 것
3. "95% 신뢰구간"을 자기 말로 한 문장 정의

**경사하강법 (인공지능 수학 1차시)**
1. 슬라이더로 감으로 최적 a 찾기 → 손실함수 최저점과 비교
2. 접선 기울기 부호와 이동 방향 규칙 발견
3. 학습률 0.045로 올려 발산 관찰 → "왜 AI는 학습률을 신중히 정하나"
